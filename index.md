## 🧰 Troubleshooting Common Problems

**The application will not start.** Check that you downloaded every file from the link and that they are all in the same folder. Missing pieces are the usual cause of startup failures.

**The bot does not respond.** Confirm that your internet connection is working and that Telegram itself is loading normally. Then disconnect and reconnect your account.

**A file will not upload.** Very large files can time out on slow connections. Try again on a stronger network, or split the file into smaller parts.

**The interface looks jumbled.** Resize the window or restart the application. Text-heavy interfaces sometimes need a fresh render to display correctly.

**You accidentally deleted something.** Deletions are permanent, so check your Telegram chat history for a previously downloaded copy. If you forwarded the file to anyone, ask them to send it back.
